## Project Overview

A modern Student Dashboard Management System developed using React.js, Bootstrap, Chart.js, React Router, Axios, and Local Storage.

## Features

* User Login & Registration
* Protected Routes
* Dashboard Analytics
* Student CRUD Operations
* Users API Integration
* Profile Page
* Settings Page
* Reports Page
* PDF Export
* Dark / Light Mode
* Responsive Design
* Toast Notifications

## Technologies Used

* React.js
* Vite
* Bootstrap 5
* React Router DOM
* Axios
* Chart.js
* React Icons
* React Toastify
* jsPDF
